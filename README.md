## 📖 About

Modern, responsive Starbucks Coffee landing page built with cutting-edge web technologies. Features elegant design, smooth animations, and intuitive user interface.

### ✨ Features

- 🎨 **Modern Design** - Elegant Starbucks-style interface with Material-UI
- 📱 **Fully Responsive** - Perfect display on all devices (mobile, tablet, desktop)
- 🎭 **Smooth Animations** - Framer Motion animations for enhanced UX
- ⚡ **High Performance** - Optimized build with Vite
- 🎯 **TypeScript** - Full type safety
- 🌙 **Dark Theme** - Stylish dark color scheme

## 🚀 Tech Stack

### Frontend
- **React 19.1.1** - UI library
- **TypeScript 5.9.3** - Static typing
- **Vite 7.1.7** - Build tool & dev server
- **Material-UI 7.3.4** - React component library
- **Tailwind CSS 4.1.15** - Utility-first CSS framework
- **Framer Motion 12.23.24** - Animation library

### Dev Tools
- **ESLint** - Code linting
- **PostCSS** - CSS post-processing
- **GH-Pages** - GitHub Pages deployment

## 🛠️ Installation & Usage

```bash
git clone https://github.com/vlad05x/starbucks.git
cd starbucks
npm install
npm run dev
```

Visit `http://localhost:5173` to view the app.

### Build & Deploy
```bash
npm run build
npm run preview
npm run deploy  # Deploy to GitHub Pages
```
